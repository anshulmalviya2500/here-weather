# Here Weather

A responsive weather application built with HTML, CSS and JavaScript using the OpenWeather API.

## Live Demo

https://hereweather.vercel.app/

## Features

- Search weather by city
- Current temperature
- Weather conditions
- Humidity
- Wind speed
- Atmospheric pressure
- Visibility
- Dynamic weather icons
- Responsive design
- Weather-based visual effects
- Error handling

## Tech Stack

- HTML5
- CSS3
- JavaScript
- OpenWeather API
